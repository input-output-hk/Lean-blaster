Reading these results fairly

  • Different toolchains & mathlib versions. A tactic's pass/fail can shift between Lean versions because available lemmas and simp sets changed — not necessarily because the tactic itself improved or regressed. Compare with that in mind.
  • ENV (⊘) is not a tactic failure. It means the theorem statement did not even elaborate on that toolchain (mathlib API drift, or a benchmark-extraction artifact), so no tactic is blamed for it.
  • lean-smt "SMT-LIB does not support lambdas". That message is a hard-coded error in lean-smt's own translator (Smt/Translate.lean), thrown on any lambda term. It is a translator gap, not a solver limitation — cvc5 itself supports higher-order reasoning and lambdas. It accounts for several STG4 failures.
