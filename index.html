How it works

    
Three steps, one command

    
Blaster doesn't just pass your goal to the solver. It first tries to close it through symbolic simplification. No SMT query needed.


    

      

        

          
        

        
Optimize

        
Beta reduction, function unfolding, let-inlining, 30+ algebraic rewriting rules

      

      
→

      

        

          
        

        
Translate

        
Lean4 types and expressions encoded as SMT-LIB V2: sorts, terms, quantifiers

      

      
→

      

        

          
        

        
Solve

        
Proof or counterexample. No manual proof required.

      

    


    

      Early exit: if the optimizer reduces the goal to True, Blaster declares Valid immediately with no SMT call. Reduction to False gives an instant Falsified. The solver only runs when symbolic reasoning is not enough.
    

  







  

    
Examples

    
What Blaster can prove

    
From first-order arithmetic to polymorphic inductive types and state machines, all with a single tactic.


    

      
      
      
      
      
    


    
    

      

        
Theorems.lean

        
-- Basic arithmetic properties
#blaster [ ∀ (a b : Nat), a + b = b + a ]
✅ Valid

#blaster [ ∀ (a b c : Int),
  (a - b) * c = a * c - b * c ]
✅ Valid

-- The solver also catches false claims
#blaster [ ∀ (n : Nat), n * n ≤ n + n ]
❌ Falsified
Counterexample: n = 3

      

      

        
First-order arithmetic

        
Integer and natural number goals are translated to SMT linear and non-linear arithmetic theories. Blaster handles equality, inequality, and modular arithmetic.

        
Nat is encoded as a bounded integer sort. Overflow and subtraction truncation semantics are preserved.

        Nat
        Int
        QF_NIA
        constant folding
      

    


    
    

      

        
Either.lean

        
inductive Either (α β : Type) where
  | Left  : α → Either α β
  | Right : β → Either α β

def isLeft  : Either a b → Bool
  | .Left _  => true  | .Right _ => false
def isRight : Either a b → Bool
  | .Left _  => false | .Right _ => true

theorem isLeft_not_isRight (x : Either α β) :
    ¬isRight x = isLeft x := by blaster
✅ Valid

theorem isLeft_or_isRight (x : Either α β) :
    isLeft x ∨ isRight x := by blaster
✅ Valid

      

      

        
Parametric & mutual inductives

        
Blaster encodes inductive types as uninterpreted SMT sorts with constructor predicates. It handles parametric types, mutually inductive definitions, and polymorphic functions over them.

        
Type parameters become universally quantified SMT sorts with predicate qualifiers to preserve constructor disjointness.

        parametric
        mutual inductive
        uninterpreted sorts
        polymorphism
      

    


    
    

      

        
Lists.lean

        
-- List length and cons
#blaster [ ∀ (x : Nat) (xs : List Nat),
  xs.length + 1 = (x :: xs).length ]
✅ Valid

-- Mutually recursive isEven / isOdd
mutual
  def isEven : Nat → Bool
    | 0   => true  | n+1 => isOdd n
  def isOdd  : Nat → Bool
    | 0   => false | n+1 => isEven n
end

#blaster [ ∀ n, isEven (n+1) = isOdd n ]
✅ Valid
#blaster [ ∀ n, isEven (n+2) → isEven n ]
✅ Valid

      

      

        
Recursive & mutually recursive

        
Blaster unfolds recursive definitions and applies algebraic normalization before SMT translation, often reducing recursive properties to straightforward quantified formulae.

        
Combine with Lean4's induction tactic to split goals that require induction; Blaster handles each case.

        recursive defs
        mutual recursion
        + induction tactic

State machine verification

        
Blaster ships with a StateMachine typeclass. Define your states, transitions, and invariants in Lean4, then use #bmc or #kind to verify them.

        
#bmc searches for invariant violations up to a given depth. #kind proves invariants hold at every reachable state via k-induction.

        #bmc
        #kind
        trace counterexamples

Concrete counterexamples

        
When the solver finds a falsifying assignment, Blaster decodes the SMT model back into a concrete Lean4 value, including nested inductive structures.

        
The counterexample is printed directly in the editor, giving you the exact witness that breaks your theorem.

        sat model decoding
        inductive values
        nested structures
      

    

  







  

    
Results

    
Three possible answers

    
Every call to blaster ends in one of three outcomes, each actionable.


    

      

        
✅ Valid

        
Theorem holds

        
The solver returned unsat for the negated goal. The tactic closes the proof with admit. Note: proof reconstruction is not yet implemented.

      

      

        
❌ Falsified

        
Counterexample found

        
The solver returned sat: the goal is provably wrong. The satisfying model is decoded into a Lean4 value and printed inline.

        

          Counterexample:

           - n: 42
        

      

      

        
? Undetermined

        
Solver gave up

        
The solver returned unknown, typically due to timeout or a formula outside decidable fragments. The goal is returned as-is for manual reasoning.

Get started

    
Add Blaster to your project

    
Two steps: declare the dependency, then call blaster.


    

      

        
Step 1: Add dependency

        
lakefile.toml

        

          
lakefile.toml

          
[[require]]
name = "Blaster"
git  = "https://github.com/input-output-hk/Lean-blaster"
rev  = "main"

        

        
lakefile.lean

        

          
lakefile.lean

          
require «Blaster» from git
  "https://github.com/input-output-hk/Lean-blaster"
  @ "main"

        

      


      

        
Step 2: Use it

        
Your Lean4 file

        

          
MyProofs.lean

          
import Blaster.Tactic

theorem addComm (a b : Nat) :
    a + b = b + a := by
  blaster
-- ✅ Valid

-- or inline, outside a proof:
#blaster [ ∀ (a b : Nat), a + b = b + a ]
-- ✅ Valid

-- with options:
#blaster (timeout: 30) (dump-smt-lib: 1)
  [ ∀ (a b : Nat), a + b = b + a ]
